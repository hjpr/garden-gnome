Small pilot complete. Generation paused.

Wild grass

Exact shared prompt

Create a NEW square terrain illustration, viewed vertically from above: a continuous dense carpet of very short meadow grass with a few tiny three-leaf clovers scattered throughout. Use the reference ONLY for fine detail scale, muted green palette and matte gouache/pencil brushwork. Thousands of tiny short grass marks point in varied directions. Clover occupies about five percent of the surface; none is a focal plant. Keep foliage size and density uniform. Invent a completely new arrangement, do not trace or reproduce the reference's clover positions or grain. Edge-to-edge vegetation under flat diffuse light. No border, empty backing, shadows, horizon, text, grid or long upright blades.

Crimson clover

Exact shared prompt

Create a NEW square terrain illustration of a dense crimson-clover canopy viewed vertically from above. Match the reference's fine scale and matte gouache/colored-pencil botanical treatment: hundreds of small overlapping three-leaf clusters, rounded oval leaflets with pale chevrons, sparse tiny crimson buds, muted forest and olive greens. Roughly thirty small leaf clusters should fit across the image width. Keep scale, density and diffuse lighting uniform across the whole square. Invent a completely new irregular arrangement rather than copying the reference. Living foliage fills every edge. Clover only: no grass, other species, oversized foreground leaves, border, white paper, vignette, grid, text or perspective.

Finding: with these reference-driven calls, fidelity and independence remain in tension. Matching an illustration is not enough if the same leaf/bud arrangement returns. This pilot does not establish that either model fails generally, only that this setup is not ready for a six-variant production batch.

Possible next experiment, not run: use a small botanical style sample instead of a complete terrain composition, then check a pair before expanding. Do not count recolors or copied layouts as independent tiles.
